## HENLACOS
Static site with Terraform, GitHub Actions and AWS using S3 + Route53 + CloudFront + ACM. Here I show the infrastructure as code, automated CI/CD and good practices of secure deployment (HTTPS via ACM).

## 🔒 Security Notice

This project uses Terraform for infrastructure management.  
Sensitive variables such as AWS credentials, account IDs, and ARNs are **never committed** to this repository.
